# 01 · 简易计算器

我的第一个独立完成的程序，使用 C++ 编写的命令行计算器。

## 功能

- 支持加法、减法、乘法、除法
- 除数为 0 时给出错误提示，程序不会崩溃
- 计算完成后可以选择“继续使用同一运算”或“返回主界面”
- 输入 0 退出程序

## 编译与运行

需要安装 g++（例如 MinGW）。在本文件夹打开终端，执行：

```bash
g++ calculator.cpp -o calculator
./calculator
```

> Windows 下如果中文显示为乱码，先执行 `chcp 65001` 把终端切换为 UTF-8 编码再运行。

## 已知问题

测试中发现：在需要输入数字的地方输入字母时，程序会陷入无限循环，不停输出“无效选择”。
原因是 `cin` 读取失败后进入失败状态，后续的输入都会被跳过。计划在下一个版本中加入输入校验来修复。
