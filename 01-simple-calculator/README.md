# 01 · 简易计算器

我的第一个独立完成的程序，使用 C++ 编写的命令行计算器。

## 功能

- 支持加法、减法、乘法、除法
- 除数为 0 时给出错误提示，程序不会崩溃
- 计算完成后可以选择“继续使用同一运算”或“返回主界面”
- 输入 0 退出程序
- 输入非数字时会提示并要求重新输入，不会卡死

## 编译与运行

需要安装 g++（例如 MinGW）。在本文件夹打开终端，执行：

```bash
g++ calculator.cpp -o calculator
./calculator
```

## 更新记录

### v0.2 · 修复输入 Bug

- **问题**：测试中发现，在需要输入数字的地方输入字母时，程序会陷入无限循环，不停输出“无效选择”。
- **原因**：`cin` 读取失败后进入失败状态，错误的输入仍留在缓冲区里，之后的读取都会直接失败。
- **修复**：新增 `readInt` / `readDouble` 两个安全读取函数。读取失败时用 `cin.clear()` 清除失败状态，用 `cin.ignore()` 丢弃错误输入，再提示用户重新输入。
- **顺带修复**：Windows 控制台中文乱码。程序启动时调用 `SetConsoleOutputCP(CP_UTF8)`，并用 `#ifdef _WIN32` 保证在其他系统上也能编译。
